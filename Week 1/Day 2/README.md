# Day 2 - Lead Management System

A simple Python lead management program built as part of my Odoo development learning journey.

## What It Does

- Collects multiple customer leads
- Stores each lead using a dictionary
- Classifies leads based on budget
- Counts leads by classification
- Tracks unique cities
- Handles invalid numeric inputs
- Displays a summary and individual lead details

## Concepts Practiced

- Lists
- Tuples
- Dictionaries
- Sets
- Loops
- Functions
- Conditions
- Exception handling with try/except
- Input validation
- enumerate()

## Lead Classification

- Premium Lead: BDT 40,000+
- Qualified Lead: BDT 25,000-39,999
- Low Budget Lead: Below BDT 25,000

```bash
python lead_manager.py
